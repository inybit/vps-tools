# xray-deploy 拆分等价性套件的函数白名单（单一权威源）
#
# 用途：tests/verify-xray-deploy-split.sh 靠「函数名集合 + 函数体逐字 diff」
#       守「其余函数体零改动」这个强保证。因此：
#         - 任何【新增函数】必须进 ALLOW_NEW，否则判「未预期新增」FAIL
#         - 任何【函数体被改动】必须进 ALLOW_CHANGED
#
# ⚠️ 为什么抽成独立文件（2026-09-21）：
#    原先白名单只在 tests/verify-xray-deploy-all.sh 里维护一份，而 run-all.sh
#    直接裸跑 split 套件、不传环境变量 → 41 个已声明新增的函数全被判「未预期
#    新增」→ 该套件在 canonical 入口下【必然 FAIL】。
#    后果不只是「多一条红」：run-all.sh 永远退非零 → 「非零 = 有回归」这个信号
#    彻底失效（真回归会被淹没在既存红里）。
#    现在两个入口都读本文件，不再各维护一份、不再漂移。
#
# 格式：每行一个函数名，# 开头为注释，空行忽略。
#       两个字段不能混（放错会被判「未预期」或漏判）。
#
